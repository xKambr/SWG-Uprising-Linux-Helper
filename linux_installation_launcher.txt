================================================================================
       STAR WARS GALAXIES: UPRISING — LINUX CLIENT SETUP & LAUNCHER
================================================================================

This package contains a custom, lightweight, native Linux setup and launcher
for Star Wars Galaxies: Uprising. It bypasses the official Windows Electron 
launcher to avoid Wine socket stalls, update crashes, and Wine subprocess bugs.

Included in this package:
  • setup_uprising.sh       - Automated prefix creation & desktop integration
  • launch_swguprising.py   - Native auto-updater, authentication & game launcher
  • README.txt              - This instruction file

--------------------------------------------------------------------------------
1. PREREQUISITES
--------------------------------------------------------------------------------
Before beginning, ensure you have:
  1. A standard Linux installation (Arch, Ubuntu/Debian, Fedora, openSUSE, etc.)
  2. Vanilla / retail SWG client files (the original 14-15 retail .tre files and
     a clean SWGEmu.exe).
  3. System packages: wine (or wine-staging), python3, and a terminal emulator
     (alacritty, kitty, foot, konsole, gnome-terminal, or xfce4-terminal).

* Note: The setup script will attempt to detect and install missing system
  packages using your distribution's package manager if permitted.

--------------------------------------------------------------------------------
2. INSTALLATION STEPS
--------------------------------------------------------------------------------

STEP 1: Unpack and make the setup script executable
  Open your terminal in the directory where these files are located and run:
    chmod +x setup_uprising.sh

STEP 2: Run the setup script
    ./setup_uprising.sh

  During execution, the script will:
    • Check for required system packages.
    • Ask where you would like to install the game prefix 
      (Default: ~/Games/SWG-Uprising).
    • Initialize an isolated Wine prefix and configure the necessary native
      dinput8 override.
    • Install launch_swguprising.py into the client directory.
    • Create a desktop shortcut on your Desktop and in your application launcher.

STEP 3: Copy your base SWG files
  Once the script finishes, copy your original game files into the client folder
  it created:
    ~/Games/SWG-Uprising/drive_c/users/<USER>/AppData/Local/Uprising/Client/

  Files that belong here:
    • bottom.tre, data_00.tre ... data_xx.tre (all original retail TRE files)
    • SWGEmu.exe

  (Do NOT worry about Uprising custom files or dinput8.dll—the launcher will
  download those automatically).

--------------------------------------------------------------------------------
3. LAUNCHING THE GAME
--------------------------------------------------------------------------------
You can launch the game in either of two ways:

  Option A (Desktop Shortcut):
    Double-click the "SWG Uprising" icon on your Desktop or open it from your
    application menu.
    * GNOME users: If using desktop icons, right-click and select "Allow Launching".

  Option B (Terminal):
    Run the launcher directly:
    ~/Games/SWG-Uprising/drive_c/users/$USER/AppData/Local/Uprising/Client/launch_swguprising.py

--------------------------------------------------------------------------------
4. HOW THE LAUNCHER WORKS
--------------------------------------------------------------------------------
Every time you launch:
  1. It performs a fast HTTP check against the remote live channel. If a game
     patch is available, it downloads only the changed/missing files.
  2. It prompts for your SWG Uprising account username and password.
  3. It completes authentication natively over UDP on Linux to avoid Wine socket
     timeouts, acquires a session token, and launches SWGEmu.exe via Wine.
  4. The terminal window will close automatically as soon as you exit the game.

--------------------------------------------------------------------------------
5. OPTIONAL: SKIP PASSWORD PROMPT
--------------------------------------------------------------------------------
If you prefer not to enter your password every time:
  1. Open launch_swguprising.py in a text editor:
     nano ~/Games/SWG-Uprising/drive_c/users/$USER/AppData/Local/Uprising/Client/launch_swguprising.py
  2. Locate the lines:
       username = input("Username: ").strip()
       password = getpass.getpass("Password: ")
  3. Replace them with:
       username = "YourUsername"
       password = "YourPassword"
  4. Save the file.
